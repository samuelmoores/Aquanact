Tracked-file summary

30 tracked files are modified relative to the baseline, with approximately
1,194 insertions and 79 deletions. The changes span editor tooling, runtime

movement.

1. Independent level-collider system
------------------------------------
- Added an independent LevelCollider data model and Scene ownership.
- Added level-collider serialization/materialization in project state.
- Added PhysicsWorld registration, update, removal, filtering, and collision
  sweeps for level colliders.
- Added box, sphere, capsule, and plane-related handling in the current code.
- Added collider transforms, scale/radius/height properties, trigger/filter
  fields, and debug visibility state.
- Entity collision is now opt-in through a controller; ordinary render-only
  entities no longer automatically participate in physics.
- Added editor selection, inspector/window support, transform gizmo controls,
  camera-path point selection, and box-face editing support.
- Added editor/runtime wireframe drawing, selected-collider highlighting,
  face arrows, face highlights, and gameplay collision-shape diagnostics.
- Added LEVEL_COLLIDER_IMPLEMENTATION_PLAN.txt as the implementation roadmap.

2. Pathed camera and camera-path tooling
----------------------------------------
- Added camera-path point editing/selection and whole-curve translation.
- Added smoother fly-camera movement using velocity response/interpolation.
- Added fly-camera look sensitivity API and state.
- Added pathed-camera follow sharpness, minimum distance, maximum distance,
  preferred lag distance, path sampling, and runtime diagnostics.
- Added path-progress direction tracking and candidate selection intended to
  keep the camera behind the player while respecting the distance band.
- Runtime camera mode now synchronizes edited camera points into the pathed
  camera when entering gameplay.
- Camera path points and camera follow settings are serialized and restored.
- Fixed project loading so camerapathsettings records are actually parsed.
