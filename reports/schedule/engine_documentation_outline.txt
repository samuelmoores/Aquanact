Window System
-------------
Source Files: `src/Engine/Window.cpp`, `include/Engine/Window.h`
Book Reference: Chapter 6.1, Subsystem Start-Up and Shut-Down; Chapter 9, Human Interface Devices
Engine Notes:
	-Window.h creates GLFW window and OpenGL context
	-owns buffer swapping and event polling
	-frame buffer size queries
	-window close state
	-startUp() init GLFW, creates window, create openGL context, makes it current, sets vsync and default window state
	-SwapBuffers() presents rendered frame, PollEvents() pumps OS event queue, GetFramebuferSize() gives render code drawable size
	-RenderManager, Input and FrontEndManager depend on it and is bottom-most app owned runtime service

Gregory Alignment:
	-classic low level engine service, small, essential and dependency root for higher level services

Deviations / Risks:
	-coupled with graphics device so not a true window class for vulkan or DX graphics
	-should only create and manage OS window, own input callbacks or have nearby platform layer with no rendering setup
	-presentation responsibility, framebuffer size and render target size, renderer assumption about context
