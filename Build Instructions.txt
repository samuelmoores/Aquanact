Aquanact Build Instructions
===========================

Requirements
------------
- CMake, Ninja, and Git.
- A vcpkg checkout. Set VCPKG_ROOT to the checkout directory.
- Windows: Visual Studio C++ build tools and Windows SDK.
- macOS: Xcode Command Line Tools.

Windows
-------
Open the x64 Native Tools Command Prompt for Visual Studio, change to the
repository root, and set VCPKG_ROOT to your vcpkg checkout. The developer
prompt initializes the MSVC and Windows SDK environment, including the
standard-library include paths required by headers such as <string>,
<filesystem>, and <cmath>. A regular Command Prompt or PowerShell window may
find cl.exe but fail to find these headers, causing C1083 errors:

    set VCPKG_ROOT=C:\path\to\vcpkg
    cmake --preset x64-debug
    cmake --build out/build/x64-debug

If a build reports that standard headers such as 'filesystem', 'cmath', or
'string' cannot be opened, rerun it from the x64 Native Tools Command Prompt.

For an optimized build, replace x64-debug with x64-release in both commands.
After building, launch the editor from its build directory:

    cd out\build\x64-debug
    .\AquanactEngine.exe

macOS (Apple Silicon)
--------------------
From a terminal at the repository root, set VCPKG_ROOT to your vcpkg checkout
and run:

    export VCPKG_ROOT=/path/to/vcpkg
    cmake --preset macos-arm64-debug
    cmake --build out/build/macos-arm64-debug

For an optimized build, replace macos-arm64-debug with macos-arm64-release in
both commands.
After building, launch the editor from its build directory:

    cd out/build/macos-arm64-debug
    ./AquanactEngine
